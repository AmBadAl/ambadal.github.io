# Amirreza Bagheridelouee's academic website

Source for [ambadal.github.io](https://ambadal.github.io), built with Jekyll and the [al-folio](https://github.com/alshedivat/al-folio) theme.

## Local development

```bash
bundle install
bundle exec jekyll serve
```

The production site is built and deployed from `main` by GitHub Actions.
